Kubernetes LLM Inference Gateway

Containerized Model Orchestration & Serving Architecture

About the Architecture

This project is a highly available, containerized inference gateway designed to orchestrate and serve large language models securely and efficiently at scale.

The inference gateway was built to solve the challenges of model deployment, resource allocation, and request routing in a distributed environment. By migrating the inference workload to a properly orchestrated Kubernetes environment, the system achieves self-healing, automated rollouts, and horizontal scaling based on inference load.

Core Components

  • FastAPI Routing Layer: Acts as the primary entry point, handling asynchronous REST requests, input validation, and secure token authentication before passing payloads to the models.
  • Ollama Integration: Manages the actual LLM weights and inference execution within isolated Docker containers, optimizing memory usage and response latency.
  • Kubernetes Orchestration: Utilizes custom Deployments, Services, and Ingress controllers to manage the lifecycle of the inference pods, ensuring high availability across nodes.
Tech Stack: Kubernetes Docker FastAPI Ollama Python
